# Task Management REST API

A backend project built using Django and Django REST Framework.

## Features
- Create task
- View tasks
- Update task
- Delete task

## Tech Stack
- Python
- Django
- SQLite

## API Endpoints
- GET /task/
- POST /task/create/
- PUT /task/update/<id>/
- DELETE /task/delete/<id>/

## Tools Used
- Postman for testing
